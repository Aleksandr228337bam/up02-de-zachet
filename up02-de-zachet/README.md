# Каталог электроники — «ЭлектроМир»

Приложение для учёта товаров и заказов магазина электроники.
Реализованы каталог с карточками товаров, оформление заказа,
управление заказами с ролевым доступом
(Клиент / Менеджер / Администратор).

## Технологии
Python, Tkinter, SQLite, Pillow.

## Функции
- Каталог с подсветкой товаров (≤3 — красным `#ff8080`).
- Скидка 25% для товаров без заказов в прошлом месяце.
- Просмотр карточки товара, добавление в заказ.
- Список заказов, состав заказа через JOIN.
- Редактирование даты и удаление позиций (только Администратор).
- Удаление заказа с восстановлением остатков.
